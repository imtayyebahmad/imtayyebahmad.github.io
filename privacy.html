Privacy Policy for Sharp Wolf AutoPoster

Last Updated: November 7, 2026

1. Introduction

Sharp Wolf AutoPoster ("we", "our", or "the Application") respects your privacy and is committed to protecting user data. This Privacy Policy explains our practices regarding the handling of information when connecting to your creator accounts across social media platforms, including TikTok, Meta (Facebook and Instagram), and YouTube via their official developer APIs.

This policy applies solely to data processed through the Sharp Wolf AutoPoster automation utility.

2. Information We Collect

We adhere to strict data minimization practices. We only process data strictly necessary to fulfill automated media publishing services:

  • Authentication Tokens & Identifiers: We securely handle OAuth access tokens, refresh tokens, and public account identifiers (e.g., TikTok OpenID, YouTube Channel ID, Meta Page ID) provided directly through standard OAuth 2.0 user authorization flows.
  • Media Content & Metadata: Short-form MP4 video files, video titles, descriptions, tags, and hashtags designated by the account administrator for automated publishing.

3. How We Use Information

Authorized credentials, API tokens, and media content are used exclusively to provide core application functionality:

  • Platform Authentication: Authenticating API requests with official third-party platform endpoints.
  • Content Publishing: Uploading, processing, and publishing scheduled video files directly to authorized creator channels, pages, and profiles.
  • Status Verification: Querying API publication status to confirm successful post completion, rendering, and upload verification.

4. Data Sharing & Third Parties

  • No Commercial Exploitation: We do not sell, rent, lease, monetize, or trade your personal data, tokens, or uploaded content to any third parties or advertising networks.
  • Direct API Transmissions: Data is transmitted solely to the respective platform APIs over secure, encrypted connections (HTTPS using TLS 1.2+):
Platform / Service API Interface Primary Purpose
TikTok TikTok Content Posting API / Open API Authenticate and publish short-form video content
Meta Meta Graph API (Facebook / Instagram) Schedule and publish video posts to pages/accounts
Google / YouTube Google Drive API & YouTube Data API Retrieve assets and execute video uploads

5. Data Storage & Security

  • Local Token Storage: All authentication credentials and access tokens are stored securely in local environment configuration files or encrypted secrets managers on your designated host infrastructure.
  • No External Tracking: We do not operate external third-party data tracking servers, telemetry services, or log personal user browsing behavior.
  • Automatic File Purging: Temporary downloaded video files and cached local media assets are automatically and immediately purged from system memory/disk upon confirmed publication or process termination.

6. User Rights & Data Revocation

You retain full control over your connected platform accounts and may revoke the Application's access permissions at any time through the respective platform security portals:

  • TikTok: Navigate to Settings > Security > Manage App Permissions and revoke access for Sharp Wolf AutoPoster.
  • Google / YouTube: Navigate to your Google Account > Security > Third-party apps with account access and remove access.
  • Meta (Facebook/Instagram): Navigate to Facebook Settings > Business Integrations and remove the application.

Upon access revocation, the Application immediately loses all ability to interact with your account, fetch profile identifiers, or publish content.
